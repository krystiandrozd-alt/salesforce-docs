# Agentforce Conversation Client — Content

Synthesis written independently from the source index below (not copied text).

Agentforce Conversation Client (ACC) is a front-end SDK for embedding employee-agent chat into both Salesforce Lightning pages and external web apps. It supports streaming responses, renders Lightning Types in the conversation, allows style-token customization, and gives programmatic control over the chat panel. Setup involves getting an employee agent ID, configuring an External Client App (ECA) for auth, generating an access token, and registering trusted domains before integrating the Web SDK into an app.
