# Plugin prompt suggestions (proposed — not installed)

Use prompts that test a **specific observable capability** instead of a generic open-ended request.

1. **Verify a price:** "Verify current EU pricing for Salesforce Communications Cloud Growth vs Advanced. Cite each product-specific source, currency, per-user denominator, annual billing qualifier and gaps. Do not log into Salesforce."
2. **Compare licensing:** "For 30 B2B sales users with Communications Cloud, compare required vs optional entitlements for Agentforce and Data 360. Cite authoritative pages, distinguish licensed user and usage charges, and mark unknown prerequisites."
3. **Replay a calculator:** "Estimate 5,000 Agentforce production actions plus 1 million Data 360 Prep rows for one month. Discover available meters; run the versioned calculator if executable, otherwise produce JSON with status NOT_RUN. Explain that the result is not a Salesforce quote."
4. **Challenge an assumption:** "Audit a proposed €0 price for Headless Platform Interaction, verify published multiplier and rate version, and refuse to represent TBA as zero."
5. **Do not execute:** "I only need public Agentforce price research. Do not install Salesforce CLI, request org credentials, or attempt an Agentforce deployment."

For changes, compare the original and proposed plugin in **identical** authorized ChatGPT runs with captured tool traces before recommending release. The actual plugin is a separate private installed artifact, not automatically updated by this repository.
